Bulk Import Exams & Questions from JSON

Paste a single exam object, or an array of exam objects, matching the schema below. Uploading with an Exam ID that already exists replaces its whole question list.

Ask Claude to turn a question paper (PDF, notes, whatever) into JSON in exactly this shape, then paste the result here.

Expected JSON Schema

[
  {
    "id": "exam_mock_51_cs",
    "title": "All India Mock Test 5",
    "subject": "Computer Science",
    "examCategory": "MCQ Mock Test",
    "durationMinutes": 60,
    "totalMarks": 200,
    "passingMarks": 80,
    "priceInInr": 0,
    "questions": [
      {
        "questionText": "Which keyword in Kotlin declares a read-only variable?",
        "options": ["var", "val", "const var", "final var"],
        "correctOptionIndex": 1,
        "explanation": "'val' creates a read-only variable in Kotlin.",
        "subject": "Kotlin Programming"
      }
    ]
  }
]

id becomes the Firestore document ID (letters/numbers/underscores, no spaces).
examCategory is either "MCQ Mock Test" or "PYQ".
correctOptionIndex is 0-based (0 = first option).
subject inside a question is optional (falls back to the exam's subject).
You can paste a single exam object (not wrapped in an array) too.
