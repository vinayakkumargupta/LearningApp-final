1. PROJECT VISION & OVERVIEW
--------------------------------------------------------------------------------
LearningApp is a modern, scalable Android mobile application designed for students
and competitive exam candidates. The app provides:
- Authentication (Login, Signup, Forgot Password).
- Tabbed Dashboard (2 Tabs):
  - Tab 1: Questions & PYQs (50-MCQ Mock Tests, Previous Year Papers with lock/unlock status).
  - Tab 2: Study Notes & Videos (PDF Notes & Video Lectures with preview and lock/unlock status).
- Search & Filter Controls:
  - Real-time search bar filtering content based on active tab.
  - Bottom filter bar chips (All, Free Access, Locked / Premium, Completed).
- Lock & Payment System:
  - Content items display "Locked 🔒" badges and price tags.
  - Simulated payment unlock pass flow that instantly unlocks content for the student.
- Test History & Performance Log:
  - Top Bar History Button on Dashboard to view all past test attempts.
  - Scorecard display featuring score, All India Rank #, Percentile %, Accuracy %,
    and a button to re-review solutions for any past test attempt.
- Full-Length 50-MCQ Mock Test Engine featuring a 60-minute countdown timer,
  interactive 1-50 question palette, answer bookmarking, automated scoring,
  All India Rank calculation, percentile analytics, and detailed step-by-step
  question solution reviews.

2. TECH STACK & DEPENDENCIES
--------------------------------------------------------------------------------
- Language: Kotlin 2.0+
- UI Framework: Jetpack Compose with Material 3 & Navigation Compose
- Dependency Injection: Dagger Hilt 2.60.1 (@HiltAndroidApp, @AndroidEntryPoint, @HiltViewModel)
- Annotation Processing: KSP (Kotlin Symbol Processing)
- Asynchronous State: Kotlin Coroutines & StateFlow / SharedFlow
- Architecture: MVVM + Repository Pattern + Clean Architecture
- Minimum SDK: 24 (Android 7.0) | Compile SDK: 35 (Android 15)

5. HOW TO DO FUTURE DEVELOPMENT & CONNECT REST APIs
--------------------------------------------------------------------------------
To connect a live REST API backend:
1. Add Retrofit/Ktor dependencies in gradle/libs.versions.toml.
2. Create API service interfaces in data/remote/ (e.g., AuthApiService, LearningApiService).
3. Create remote repository implementations (e.g., RemoteAuthRepositoryImpl, RemoteLearningRepositoryImpl).
4. Update Dagger Hilt bindings in app/src/main/java/com/univ/learningapp/di/RepositoryModule.kt:
   Change @Binds implementations from local mock classes to remote classes.
5. All ViewModels and Composables consume Domain Repository Interfaces, so no UI code changes are needed!
